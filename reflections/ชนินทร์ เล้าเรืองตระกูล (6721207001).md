# Reflection — <ชนินทร์ เล้าเรืองตระกูล> (<6721207001>)

## 1. ส่วนใดของงานที่ฉันใช้ AI ช่วยมากที่สุด เพราะอะไร
ใช้ในการ research inspiration Theme Lighthouse analyze check เพราะบางทีแม้จะให้ AI ไปหาข้อมูลมันก็มั่วจึงถึงไปหาเอาเองกับแรงบัลดาลใจตามเว็บต่างๆถ้าให้ AI ออกแบบให้น่าจะแย่

## 2. มีครั้งใดที่ AI ให้คำตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
คำตอบมั่วๆที่เห็นชัดเจนว่ามันผิดข้อมูลเท็จครั้งแรกที่ทำมันเอาข้อมูล Mock up ขึ้นมา ชมรมที่มไม่อยู่จริงก็มีอยู่ใน API จึงต้องสั่งมันให้หาข้อมูลจริงๆตาม page มหาลัย 


## 3. หลังทำโปรเจกต์ มีเรื่องใดที่ฉันเข้าใจและทำได้ด้วยตนเองโดยไม่ต้องพึ่ง AI แล้ว
API การดึงข้อมูลจากระบบที่มีอยู่จริงส่วนใหญ่ต้องไปขอหรือได้รับอนุญาติก่อน 
Cloudflare ที่จะ block ไม่ให้พวก Bot/AI เข้ามาหาข้อมูลที่จ้าง cloudflare เข้ามาดูแล website จึงต้องมานั่งค้นหาเอาเอง
